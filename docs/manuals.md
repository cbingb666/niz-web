# Manufacturer keyboard manuals

**English** · [简体中文](manuals.zh-CN.md)

[Back to user guide](usage.md) · [Vendor material notes (Chinese)](../drivers/README.md)

Original manuals for the four supported models: ATOM66, ATOM68, MICRO82 and MICRO84. The collection contains 16 Word manuals (eight English/Chinese pairs) and 12 Chinese layout and function PDFs. Original filenames, formats and contents are preserved.

Check the keyboard label, then choose its model and variant below. The Word manuals cover keyboard functions and the original Windows programming software. For NIZ Web operations, use the [user guide](usage.md).

## Versions and applicability

The wireless Word titles use `Ble` for Bluetooth versions, while the wireless PDFs use “tri-mode”. Their descriptions of modes, shortcuts and functions differ. The Word manuals are not English translations of the Chinese PDFs. Match layouts and built-in functions to the actual keyboard revision. This index does not extend Web support.

ATOM66 configuration operations have been verified on a real keyboard. ATOM68, MICRO82 and MICRO84 remain hardware-unverified. ATOM68 Pro, MICRO82 Pro, MINI84 and other 84-key families are outside this collection.
