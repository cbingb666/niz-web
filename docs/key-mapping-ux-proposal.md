# 按键映射交互改版方案

状态：首批已落地；后续布局已改为编号键位、多层同时展示，旧交互示意仅用于记录初始方案。交互示意使用演示数据。正式页面已实现目标功能选择、快捷键编辑与录入、逐键候选草稿、事务撤销 / 重做、Fn 联动和差异预览。宏步骤可视化等后续内容仍是提案。未连接或写入真实硬件。

## 推荐方向

采用「键盘画布 + 上下文编辑器 + 统一写入」工作台。

主流程：**点击编号键位中的目标层 → 选择目标功能 → 自动暂存 → 核对差异 → 写入键盘**。默认编辑普通层，也可在编辑器切换层。

普通改键不出现“模式”和“按键序列”表单。快捷键、连发和宏根据用户选择展示专用控件。所有改动先进入待写入配置；只有明确确认写入后才访问硬件。

本提案针对桌面 Chrome / Edge 和当前 ATOM66 能力。保留现有型号抽象、中英文、本地导入导出、备份及硬件事务，不新增固件能力。

## 现状与问题

以下为代码走查结论，尚未进行用户访谈或可用性测试。

| 现状 | 交互问题 | 建议 |
| --- | --- | --- |
| 单键、组合键、宏共用模式选择和多行序列输入 | 改一个普通键也要理解序列语法；同时按下与依次执行容易混淆 | 按用户目的拆分编辑入口 |
| 搜索依赖原生 datalist，名称后带数字代码 | 名称、固件功能和保留代码混杂，选择后还需添加 | 可搜索的功能选择器，点击即选择；数字代码进入高级信息 |
| “保存此键修改”与“写入键盘”同时存在 | 用户难判断何时生效 | 普通修改自动暂存；仅硬件写入保留全局主按钮 |
| 切键、导出、写入已调用 `saveForm()` | 实际存在自动保存，但界面没有清楚表达；无效表单阻止切键 | 展示统一状态；复杂编辑独立保存候选草稿，错误就地呈现 |
| Fn 赋值同步三个可编辑层 | 单键操作实际可能改变三条记录，影响范围不明显 | 在选择器、差异预览和撤销中展示跨层影响 |
| 还原此键恢复到载入时的 baseline | 容易被理解为恢复出厂 | 文案改为“还原此键至载入时”；来源为设备时可写“还原至读取时” |
| 日志、计数、灯光、文件操作同时占据编辑区 | 抢占主任务注意力 | 主区只围绕映射；其他能力进入独立工具区或折叠详情 |

相关实现：`src/components/key-editor.tsx`、`src/components/keyboard-panel.tsx`、`src/store/app-store.ts`、`src/editor.ts`、`src/protocol.ts`。

## 页面结构

1. **顶部设备栏**：型号、连接状态、配置来源；连接 / 读取操作清晰区分。导入、导出和备份保留在工具菜单。演示配置始终标记“离线演示”。
2. **键盘上方**：普通层、右 Fn 层、左 Fn 层三个切换入口，分别显示待写入的映射数量。Fn 层下面解释“按住右 / 左 Fn 时生效”。
3. **键盘画布**：保留真实物理布局。编号作为定位信息，同时显示所有可编辑层的当前映射；每层独立支持点击、悬停和焦点。仅当前键帽和具体选中映射以背景色高亮，不联动其他键位、不显示选中边框，待写入标记与候选标记分别归属对应层。
4. **上下文编辑器**：固定在右侧，连续改多个键时不反复开关弹窗。标题始终显示“层 · 物理键”，并展示当前目标功能。较窄屏幕改到键盘下方。
5. **底部提交栏**：显示“已暂存，尚未写入键盘”、受影响物理键数和映射数，提供撤销、重做和“核对并写入”。

设备连接、离线来源、编辑状态是三种独立信息。不得用“已连接”暗示配置已读取，也不得用“已保存”暗示键盘已生效。

## 四类编辑入口

| 入口 | 默认控件 | 提交行为 |
| --- | --- | --- |
| 按键 | 搜索 + 常用按键；可按字母、修饰键、导航键、功能键查找 | 点击有效目标立即暂存，键帽同步更新 |
| 快捷键 | 修饰键标签 + 主键；可选页面内按键录入 | 录入时先预览组合，点“使用此快捷键”后作为一个操作暂存 |
| 系统功能 | 媒体、鼠标、Fn、设备功能等分组 | 普通有效功能点击即暂存；Fn 显示跨层范围 |
| 宏 / 连发 | 连发编辑器或步骤列表；只显示当前模式需要的参数 | 点“应用宏 / 连发”后整笔暂存 |

快捷键文案必须表达“同时按下”，宏文案表达“依次执行”。保留当前协议支持的组合键能力，不人为缩减为只能选择一个修饰键；常见单主键组合是简化入口，高级模式仍能表达原有配置。

快捷键录入只在用户显式开启、录入区域有焦点时捕获输入；退出该区域或切换键位即停止。保留鼠标选择作为完整替代路径。不要承诺能捕获所有系统快捷键，不使用全局按键监听来猜测用户选中了哪一个物理键。

宏以步骤行表达按键，以行间控件表达延迟，最后一步不显示“下一步延迟”。支持统一间隔和逐步间隔，以及“指定次数 / 按住播放 / 再次按下停止”。不引入当前协议没有表达的按下/抬起事件、应用条件、任意脚本或宏步骤内组合语义。保留文本高级编辑入口用于兼容已有输入习惯。

未识别功能保留原值并标注，不能静默转为无功能。保留代码放在高级入口；功能码是否在设备上可用仍按已确认的能力说明，不凭 UI 分组宣称已验证。

## 编辑与恢复规则

- **普通修改**：选择完成即更新内存配置和差异列表。不访问 USB，不新增单键保存按钮。
- **复杂候选**：快捷键录入和宏表单按“配置版本 + 层 + 物理键”保留候选内容。切键后能回来继续编辑；不强迫用户先修正一个错误才能查看其他键。
- **未完成候选**：字段旁显示原因；底栏提示有几处尚未应用的编辑。写入前必须完成或显式放弃这些候选，禁止悄悄遗漏它们。
- **撤销 / 重做**：以一次用户动作作为边界。Fn 的多层修改一次撤回；再次编辑后清空重做栈。输入框内保留原生文本撤销，不抢占其快捷键。
- **还原此键**：恢复到当前配置载入时的基准，也是一条可撤销操作。离线导入时不能把这个基准称为“设备原值”。
- **会话边界**：重新读取、导入替换、模拟或真实写入成功后建立新的基准；处理现有草稿后再清空旧历史，不能把旧会话撤销命令应用到新配置。
- **离开页面**：仅存在修改或未完成候选时提示。第一版不承诺刷新恢复；“暂存”不表示已持久化。后续若做 IndexedDB 草稿恢复，应绑定型号、固件和配置基准，并与备份区分。

## Fn 的特殊处理

给任意物理键分配左 / 右 Fn 时，在执行前的可见说明中标明“此位置的三个层会一起改变”，同步更新三层并记录为一个可撤销事务。

移除现有 Fn 也需要一个明确的跨层操作，避免只覆盖普通层后残留不一致的 Fn 映射。显示即将覆盖的三层内容；最后一个 Fn 不允许移除，提示“先把另一个键设为 Fn”。保留写入前的完整 Fn 校验，不以界面约束代替协议保护。

Fn 层的“未设置”保持当前配置语义，不显示为“继承普通层”，除非后续硬件验证明确支持这种解释。

## 核对与写入

点击“核对并写入”后展示实际差异，而不只列出位置：

| 层 | 物理键 | 读取时 | 即将写入 |
| --- | --- | --- | --- |
| 普通层 | Caps Lock | Caps Lock | Esc |
| 右 Fn 层 | J | 未设置 | ← |

同时显示配置来源、设备身份、受影响键位与映射数量，以及“读写期间键盘暂时不能输入”的现有提示。仅这一处确认真正触发硬件事务。

保留写前再次读取、外部变更检查、本地备份、写入、回读验证的完整流程。进度按真实阶段显示；未收到总量时不编造百分比。成功只在回读验证通过后显示，并更新基准、清除相应待写入标记。失败保留草稿并提供明确下一步，不自动重试或声称已恢复。

未连接、演示模式、未读取设备基准或连接已过期时，显示对应原因和可执行入口，不把一个无解释的灰色按钮留给用户。重新连接不能绕过现有配置保护；先按已有读取流程建立当前设备基准，再确认如何处理草稿。

## 可访问性与小屏

- 真实页面保留键盘方向键导航，层和目标功能可用键盘操作；目标切换不强抢焦点。
- 键帽无障碍名称包括层、物理位置、当前映射、是否待写入；重复的左右 Ctrl / Shift 等有独立名称。
- 搜索结果支持方向键、Enter 选择、Escape 关闭；输入法组合期间不误提交。所有核心操作有文字名称，不依赖悬停或颜色。
- 保留完整物理错列和长键比例；采用参考图中的正视阶梯键帽轮廓，并使用与页面统一的深色配色和随键宽调整的高度，正面上部为大号普通层，正面下部为小号左 Fn，底部侧面为小号右 Fn，左侧面为小号编号。窄屏编辑器下移，键盘横向查看，不改排为规则网格。
- 中英文标签属于显示层，键码和配置语义不随语言改变。

## 落地顺序

**第一批：改善最常用路径。** 拆分普通按键与快捷键选择器，取消普通修改的保存按钮，增加明确暂存状态、事务撤销、差异预览和 Fn 范围提示；保留复杂编辑原有能力及所有硬件保护。

**第二批：降低复杂操作成本。** 宏步骤编辑器、错误精确定位到步骤和跨层对照。按键录入与按键级候选草稿已在首批一并实现。跨键批量编辑、自动推荐、云端配置、全局录制不进入本次改版。

架构上可复用 `EditorState.applyDefinitions()`、`Profile` 和现有写入链路。新增“功能选择器 / 快捷键编辑器 / 宏编辑器 / 差异预览”界面，调整 store 的候选草稿与撤销事务，不把硬件调用放进组件的选择事件。

## 验收方式

以下是后续可用性验证任务，不是已经测得的提升：

1. 首次用户把 Caps Lock 改为 Esc：在已载入配置后，默认常用区中只需点键位和点 Esc 两次选择即可暂存，不输入文本或操作“添加”。
2. 连续修改三个键，再撤回第二个键的修改；用户能理解差异列表和全局撤销的区别。
3. 只修改右 Fn 层的 J 为左箭头，普通层不变；再添加一个 Fn，能够说出为何三个层都有差异。
4. 编辑到一半的宏切换到另一个键，再返回；内容仍在，不能在没有处理候选的情况下悄悄写入。
5. 指出“待写入”“离线演示”“已写入并验证”的不同含义；不会因选择目标功能就认为键盘已生效。
6. 中断写入或切换设备后，界面保留修改并引导重新读取核对，而不是直接重新写入。

交互示意范围：选键、切层、搜索目标、快捷键、简单宏 / 连发、暂存、撤销 / 重做、Fn 联动、差异预览和模拟完成。它不连接设备，不验证固件，不涵盖完整功能码或真实失败流程。
