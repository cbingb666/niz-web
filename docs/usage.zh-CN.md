# 使用指南

[English](usage.md) · **简体中文**

[返回 README](../README.zh-CN.md) · [报告问题](https://github.com/cbingb666/niz-web/issues/new?template=bug-report.yml)

目前支持 ATOM66、ATOM68、MICRO82 和 MICRO84。ATOM66 已实机验证；其余三款依据官方软件分析适配，未实机验证。首次使用先读取、核对并下载备份；详细范围见[验证记录](../VALIDATION.md)。

内置快捷键、蓝牙配对和实体布局见[原厂说明书索引](manuals.zh-CN.md)，可按型号打开原始中英文资料。

点击顶栏的书本图标「键盘手册」打开手册弹窗，再选择 ATOM66、ATOM68、MICRO82 或 MICRO84。各型号按版本列出中文布局与功能 PDF，以及资料包提供的中英文 Word 手册。PDF 在新标签页查看，Word 下载后打开。选择型号和查看手册不会切换当前编辑的设备，也不会清空编辑内容。

手册需联网查阅，独立 HTML 也一样。PDF 与 Word 可能对应不同版本，请核对键盘铭牌；缺少某种语言或格式时，不使用其他版本代替。

## 连接与读取

使用桌面版 Chrome 或 Edge，在独立标签页打开 [NIZ Web](https://cbingb666.github.io/niz-web/)。通过 USB 数据线连接键盘，退出其他键盘配置工具。浏览器要求见 [Chrome 的 WebHID 说明](https://developer.chrome.com/docs/capabilities/hid)。

点击「连接设备」，依次完成四步：

1. 核对键盘底部铭牌，确认型号受支持。
2. 接好 USB 数据线。
3. 点击「连接键盘」，在浏览器窗口中选择设备并授权。
4. 点击「下一步」，再点击「查看设备」，返回设备管理。

ATOM66 配置时需要键盘的 **Win 模式**，Mac 电脑也一样。按住任意一侧 **Fn＋左 Alt** 3 秒：状态灯闪 1 次表示 Win 模式，闪 2 次表示 Mac 模式。等待 USB 重新连接，再打开浏览器选择窗口。详见 [ATOM66 原厂说明书](manuals.zh-CN.md#atom66)。连接引导的「连接遇到问题？」中也提供了这条提示。

**连接不会自动读取配置。** 在设备卡片上点击「配置设备」，确认「开始读取」后才会读取并尝试保存本地备份。读取成功后，先导出 JSON 留存。

读写期间键盘暂时锁定，无法输入，页面也不能进行其他操作。等待完成后再继续；取消读取确认不会发送配置读取命令。

### 多台设备与断开

每台键盘有独立的设备卡片、配置、草稿和撤销历史。连接另一台键盘不会切换当前编辑内容；取消授权或重复选择同一台也不会断开已有设备。设备编号只用于区分当前页面中的键盘，不是硬件序列号。

卡片显示配置是否已读取，以及是否有未写入的修改。点击「配置设备」会在需要时请求读取确认；已有当前连接的配置时，直接返回该设备的编辑器，不会再次读取。「断开」图标位于卡片右上角，支持校准的设备会在「配置设备」旁显示「校准按键」。点击其左侧的信息图标，打开「设备详情」弹窗，查看固件和 USB 标识。打开详情不会发送设备命令，也不会切换当前编辑器。

当前编辑的键盘断开后，页面返回设备管理，编辑内容列在「保留的编辑内容」中。点击「继续编辑」可以离线查看或导出。这些内容只保留在当前页面；关闭页面前请保存需要的配置。

点击「断开」会打开显示键盘名称的确认弹窗，默认聚焦「取消」。确认「断开」后才关闭连接并尝试撤销此网站的设备授权，下次需要重新选择键盘。取消会保持连接；连接变化会取消旧确认。编辑内容仍保留在页面中。拔线或关闭页面不会撤销授权；如果浏览器不支持撤销，按页面提示在网站设置中移除设备授权。

## 编辑按键

每个键位显示普通层、右 Fn 层和左 Fn 层。点击要修改的那一层映射，再选择功能。可用中文、英文或缩写搜索；勾选「显示编码」可查看键位编号。

方向键支持「箭头」「方向键」「左」「右」「上」「下」，以及「向左」「左箭头」「左方向键」等名称；也支持 `arrow`、`left`、`right`、`up`、`down`，以及 `arrow left`、`left arrow`、`ArrowLeft` 等英文写法。

功能分类中「全部」排在「常用」前面，默认选择「全部」。搜索覆盖全部分类，并显示结果数量。「清除搜索」会返回之前浏览的分类。在搜索框中按下方向键聚焦首个结果，再用方向键浏览、Enter 选择。Esc 返回搜索框，再按一次会清除搜索。

「按键与功能」在同一个列表中提供普通按键和系统功能。切换键位或层时，面板保留编辑方式、分类、搜索词和功能列表中正在浏览的位置；暂存修改后再换键，也保留该位置。快捷键的主键列表独立保留搜索与分类。返回有未应用输入的键位时，会恢复该键位的草稿编辑器。

搜索框下的「最近使用」显示最近成功暂存的最多 6 个不同功能，最新的排在前面。即使功能不在当前搜索或分类中，也可直接点击分配。浏览状态和最近使用按设备独立保存在此页面，刷新后清空。最近使用仍遵守草稿、Fn 和固件检查；所有分配都先暂存，确认写入后才会改变键盘。

编辑栏摘要显示当前键位、层和功能，并标明未应用输入或已暂存修改。点击顶栏「设备管理」返回设备列表，编辑内容会保留。底栏右侧提供可见的「导入」「导出」按钮；离线编辑时，也可从底栏连接键盘或选择已连接的设备。

| 要修改的内容 | 操作 |
| --- | --- |
| 普通按键或系统功能 | 点击目标功能即暂存 |
| 将映射设为未设置 | 选择「未设置」，键帽显示「—」 |
| 快捷键 | 选择修饰键和主键，完成后点击「使用此快捷键」 |
| 宏或连发 | 编辑内容与执行参数，完成后点击「应用这次编辑」 |
| 当前键位恢复原值 | 点击「还原」，恢复载入时的配置 |
| 检查全部修改 | 点击键盘工具栏的「待写入改动」，按层对照「载入时」与「修改后」。点击键位旁的「编辑」返回对应键位；展开「功能详情」查看宏序列 |

快捷键录入需要手动开启。Esc 取消；Tab 停止录入并允许移动到下一个控件。按钮或窗口失去焦点也会停止录入。需要在快捷键中使用 Tab、Esc 或系统保留按键时，可从功能列表中选择。宏支持固定次数、按住执行、再次按下停止，以及统一间隔或逐步延迟。

切换键位、映射类型、语言、页面或设备时，未应用的输入会随原键位和层保留。如果切换到无法编辑当前草稿的选择器，功能选项会暂时禁用，直到应用或放弃这次编辑。点击「继续编辑」可返回草稿。编辑内容滚动时，应用、放弃按钮和编辑错误仍保留在编辑栏底部。导出和写入前，需要先应用或放弃这些输入。

撤销与重做最多保留 50 笔已应用操作，包括批量改键、Fn 联动和灯光修改。重新载入配置或成功写入后，历史会清空。「还原」不是恢复出厂设置。

分配或移除 Fn 会同步三个可编辑层，且必须至少保留一个 Fn。

### 键盘操作与计数

- 方向键：在当前层选择相邻键位。
- `Alt` + 上 / 下：切换当前键位的编辑层。
- 「显示计数」：在键帽底部显示按键次数，临时替代右 Fn 映射。关闭后可继续编辑右 Fn。

缺失计数显示「—」，不等同于零。开启计数时，普通层和左 Fn 仍可编辑。

### macOS 屏幕亮度

搜索「屏幕亮度」可找到带有 macOS 用途说明的 `Scroll Lock` 和 `Pause`，分别对应降低、提高屏幕亮度，参见 [QMK 按键说明](https://docs.qmk.fm/keycodes_basic#lock-keys)。「亮度 − / +」指键盘灯光亮度。

这条兼容路径尚未在真实 ATOM66 与 macOS 上验证。外接显示器还需支持系统亮度控制，参见 [Apple 快捷键说明](https://support.apple.com/en-us/102650)。

### Mac 原生系统键（实验）

ATOM66 RGB BLE V1.5.1 / V1.5.1-F.1 的「Mac 系统键」提供原生屏幕亮度码。V1.5.1-F.1 另增加调度中心、Launchpad、Spotlight、听写、勿扰、系统键盘背光及快退/快进。其他已载入型号或版本禁用不适用选项；高级编辑手动输入原始码也不能写入不支持的目标。映射与固件操作见 [Mac 原生固件](../niz-firmware/firmware/MAC_NATIVE.zh-CN.md)。

配置和刷写使用 Win 模式。刷写后主动读取新配置，再编辑。Apple Fn 与系统背光使用原厂 Mac 模式，仍需实机验证；蓝牙效果未验证，勿扰仅支持 USB。发出原生 HID 码不代表每项 macOS 系统动作都已通过验收。

## 核对与写入

编辑只暂存在页面中，确认写入后才会更改键盘。

1. 点击底栏的「核对并写入」，也可在允许写入时从「待写入改动」弹窗进入。
2. 核对改动数量，按需展开「查看改动明细」。
3. 确认「开始写入」，等待整个操作结束。

程序会先读取键盘，检查配置是否被其他工具改动；本地备份保存成功后才开始写入，最后回读核对结果。一次确认覆盖整个过程。

进度只表示**当前阶段**的数据传输量。初次读取、写前检查、备份和等待阶段没有可用的总量，因此不会显示百分比。发送完成后仍需等待回读验证。

写入不能保证中断时恢复原状。拔线、休眠或设备错误可能造成部分写入；程序不会自动重试或回滚。失败后重新连接、读取并核对，再决定是否恢复备份。

## 备份与恢复

**建议在浏览器备份之外，另行下载 JSON。** 本地备份属于当前浏览器和当前网址，清理站点数据、浏览器回收存储或更换网址后可能不可用。

重复读取、配置写入前和固件刷写前的备份，如果型号、固件、保存的设备信息、完整键位和灯光相同，会复用同一条记录，更新最近备份时间、来源和可用的按键计数；仅计数变化不新增版本。后续读取没有计数时，保留之前保存的计数。配置发生变化时保留独立版本。已有重复备份也只显示最近的一份，旧存储记录不会被删除。

「本地备份」只滚动列表，头部与关闭按钮保持可见。点击备份旁的「删除」后需要确认，默认聚焦「取消」。删除会清除当前浏览器中的该配置及其旧重复备份，无法撤销；如需保留，请先下载。键盘配置和当前编辑内容会保留。

恢复文件中的配置：

1. 连接目标键盘，确认读取当前配置。
2. 导入之前保存的 JSON，或从「本地备份」中选择配置。
3. 核对导入后的内容，点击「核对并写入」并确认。

支持导入兼容的原生版 JSON，以及 ATOM66、ATOM68、MICRO82 和 MICRO84 的 Windows `.pro` 文件，导出为完整 JSON。不同型号的配置不能混用。

升级或降级固件后，主动读取键盘，再导入旧 JSON 或本地备份。同一型号且使用已支持配置协议时，固件版本字符串不同不会阻止导入。可编辑层的键位、快捷键和宏会转换到当前配置；隐藏扩展组、设备信息和计数保留当前键盘的数据。仅当两份配置都支持逐键灯光时才迁移灯光。导入只暂存修改，仍需通过「检查并写入」完成备份、写入与回读验证。

无法转换、包含未识别功能码或不受支持的 Mac 功能的映射会保留键盘当前值。提示会列出具体键位、层、原映射和保留值；联动的 Fn 层一起保留。需要时点击「继续编辑」重新分配，这些未迁移键位也会保留在「操作记录」中。不根据版本号猜测未知 Mac 专用码是否可用；使用其他尚未实现协议的固件仍需单独适配。离线导入保留文件原版本，直到主动读取目标键盘并再次导入。迁移已覆盖自动化模拟测试，尚未实机验证。

ATOM66 支持三组或九组配置，界面只编辑前三组。九组配置的其余六组会原样保留；向已读取的九组键盘导入三组文件时，也会保留设备原有的扩展组。

ATOM68 的原厂配置为六组，Windows `.pro` 文件也包含六组。界面编辑前三组，保留其余三组；读取设备后导入三组 JSON，同样保留已有扩展组。本次适配不包含 ATOM68 Pro。

MICRO82 和 MICRO84 适配原有 82EC / 84EC 软件系列，本次核对的原厂客户端与 `.pro` 文件为三组。长空格和双 Fn 布局属于两个独立型号，不包含 MICRO82 Pro、MINI84 或其他 84 键系列。这两款 MICRO 暂不提供校准。

离线演示和离线导入不代表当前键盘状态。要将离线编辑写入键盘，先导出，再连接并读取目标键盘，最后重新导入文件。

「操作记录」可导出读取诊断，用于排查报文问题。**读取诊断不是恢复备份，不能直接导入写入。** 配置、计数和诊断不会自动上传，下载后请自行保管。

## 语言与离线使用

### 页面链接与浏览器导航

页面使用 `#` 后的地址片段，因此同样的链接适用于仓库子路径和独立 HTML 文件。

| URL 片段 | 页面 |
| --- | --- |
| `#/devices` | 设备管理 |
| `#/connect` | 连接引导 |
| `#/demo` | 演示键盘选择 |
| `#/demo/atom66` | ATOM66 离线编辑器 |
| `#/demo/atom68` | ATOM68 离线编辑器 |
| `#/demo/micro82` | MICRO82 离线编辑器 |
| `#/demo/micro84` | MICRO84 离线编辑器 |
| `#/editor` | 当前页面已载入的配置 |

选择页会在 URL 中记录型号和返回入口，例如 `#/demo?model=atom68&from=connect`。更换型号只更新当前历史项，不额外增加一步。浏览器前进、后退保留已载入配置和未应用输入；离开有编辑的工作台时请求确认。取消后恢复原 URL，并保留历史项。读写确认、读取、写入或校准期间，历史导航不会解除当前操作的锁定。

可重新打开连接引导或演示选择链接。新载入的连接引导从型号检查开始，仍须按正常流程点击按钮；指定型号的演示链接载入离线示例。URL 不包含配置、草稿或 USB 授权：刷新会丢失未保存的页面数据，空的 `#/editor` 会返回设备管理。打开或修改 URL 不会授权 USB，也不会读取或写入硬件配置。

右上角可切换简体中文和英文，切换不会清空输入或重新连接设备。页面优先使用已保存的语言选择，其次匹配浏览器语言，无法匹配时使用简体中文。

没有键盘时，可在设备管理空状态或连接引导点击「离线演示」。在下一页选择型号卡片，再点击「开始演示」。可用返回按钮回到原入口，连接引导会保留当前步骤。切换页面或语言会保留所选型号。选择型号不会替换当前配置；开始演示时，若已有暂存修改或未应用输入，会先请求替换确认。取消后保留编辑内容和所选演示型号。离线演示不请求 USB 授权，也不读取或写入键盘。

构建得到的 `dist/index.html` 包含全部运行时资源和翻译，可离线导入、编辑和导出。直接打开本地 HTML 时，USB 和备份权限取决于浏览器，尚未完成实机验证。

## 按键校准

开发环境和生产构建默认提供校准，无需环境开关，已开放以下 ATOM66 组合：

| 设备 | VID/PID | 完整固件 |
| --- | --- | --- |
| `66EC-S` | `0483:522A` | `66EC(S);V1.4.4;V1.0;` |
| `66EC-XRGB` | `0483:502A` | `66EC(XRGB)BLe;V1.2.5;V1.0;` |

同时要求匹配配置接口，其他组合仍不可用。校准效果尚未经过实机验证，配置备份不能恢复校准数据。

在目标设备卡片选择「校准按键」。这不会切换当前编辑器或读取键位配置，既有编辑和草稿继续保留。

1. 松开全部按键。可选择记录本地诊断，再点击「开始校准」，取消默认获得焦点。请用鼠标或触控板操作；用 Enter/Space 启动时，需松开启动用键后才会开始。
2. 等待释放校准完成。用力按住一个或几个异常键，点击「校准按住的键」，保持按住直到完成提示后再松开。可继续处理另一组，或点击「结束并解锁」。按下校准不是必做步骤。
3. 解锁命令发送后，在本地试键区检查异常键。试键文字不进入诊断；人工检查不能证明所有传感器正常或校准已永久保存。

硬件会话期间页面持续锁定，包括等待用户按住按键的阶段。通信中不能用 Escape 或背景点击关闭。已完成阶段之间通过「结束并解锁」退出，不代表撤销校准。不自动重试校准，也不自动回滚。

发出会改变校准的命令后，目标设备的硬件写入基线失效，载入配置、已暂存修改、草稿和撤销历史仍保留。之后如需写入配置，请先保留编辑，再按既有流程主动重读/导入。校准不会自动重载编辑器。

操作失败后页面解除锁定，设备页保留可查看的错误，即使该设备从未载入配置。失败连接不会自动恢复。解锁报文已发送不等于输入已恢复，发送挂起或断线可能使结果不确定。请先检查键盘，仍异常时使用原厂工具或联系原厂支持，恢复后主动重新连接并读取配置。不能保证重新插线或关闭标签页能够恢复；浏览器崩溃或强制关闭后也不能保证自动解锁。

开始前开启记录时，「导出校准诊断」可下载本次有数量限制的报文记录。它不是校准备份，也不能作为配置导入。不上传诊断，不记录普通试键文字。

## 固件刷写

**实验功能，尚未实机验证。** 设备卡片仅对 ATOM66 / 66EC RGB BLE 的 USB `0483:542A`、固件 `66EC(RGB)BLe;V1.5.1;V1.0;` 或 `66EC(RGB)BLe;V1.5.1-F.1;V1.0;` 及匹配的 64 字节配置接口显示「刷写固件（实验）」。工具接受精确的原厂 V1.5.1 和 Mac V1.5.1-F.1 实验包，可在此目标设备上切换这两个构建；其他版本和 ATOM66 变体仍不支持。

1. 在「设备管理」打开「刷写固件（实验）」，选择原始 `66EC(RGB)BLe_V1.5.1_20230520.bin` 逐字节一致的 stock 重建包，或精确的 `66EC_RGB_BLE_V1.5.1-F.1.bin` 实验构建。工具核对精确 SHA-256，拒绝原始镜像、普通 HEX、未识别的修改包和实验 `c_scan` 包。确认前核对显示的目标版本及 Mac 实验版限制。升级包只在本地处理，不随网页分发，不需要提前手动读取配置。若这台键盘有未应用输入，请先完成或放弃。
2. 准备原厂升级工具及适用于这台键盘的恢复方法。**配置备份不能恢复固件。** 阅读键盘无法输入的提示，再点击「开始写入」。一次确认覆盖设备核对、自动读取当前键位、灯光和按键计数、完成本地备份及发送固件；读取或备份失败会阻止固件传输。即使页面已载入旧配置，备份也以此次刚读到的设备状态为准；暂存编辑保留在页面中。
3. 保持 USB 连接和页面打开。百分比只表示已发送报文，不表示固件已安装。传输结束后等待设备断开；未观察到断开时，结果保持「尚未确认重启」。超时不代表可以安全拔线。
4. 观察到断开重启后，点击「选择键盘并核对版本」，明确选择刚刷写的键盘。此操作只查询版本；网页无法通过 USB 型号和版本区分相同的实体键盘，请选对设备。版本相符也不能证明固件逐字节一致，还须测试全部按键、RGB、USB/BLE 和断电后的配置保存。

设备拒绝、异常回复、传输中断或发送超时都会停止后续报文，不自动重试、回滚或发送解锁命令。固件传输一旦尝试，旧配置基线就会失效。保留本地编辑，再次写入配置前主动重新读取。「设备管理」中的结果及其备份下载保留在当前页面会话内，刷新后不会恢复。

失败时按原厂工具说明检查设备和恢复方法。USB 更新时序、引导程序从 EEPROM 写回 APROM、实际重启和故障恢复仍未验证。如果设备应用或引导程序已经不再暴露预期接口，可能需要网页之外的恢复方法。

## 常见问题

### 浏览器里找不到键盘

确认使用支持 WebHID 的桌面版 Chrome 或 Edge，USB 数据线已接好，其他配置工具已退出。在独立标签页打开 HTTPS 页面，按页面中的环境提示排查；嵌入其他应用的网页可能没有设备访问权限。

Safari 等未提供所需 WebHID 接口的浏览器只能使用离线功能。不要通过关闭浏览器安全限制来连接设备。

### 读取取消或失败

再次点击「配置设备」或「重新读取配置」重试。页面不会循环弹窗或自动重读；保留错误文字，必要时从「操作记录」导出诊断。

### 重连后不能直接写入

连接已变化，需要重新读取并确认当前键盘状态。如有未写入的修改，先导出保存，再读取设备并重新导入。

### 设备配置已发生变化

尝试写入时出现这条错误，请检查键盘是否已进入编程模式。先导出编辑内容，再重新读取键盘并导入文件。

### 本地备份失败

先导出当前配置，检查浏览器存储空间与隐私设置。写入前必须成功保存本地备份；仅下载文件不能跳过这项检查。

### 鼠标、媒体或灯光功能没有生效

页面提供原厂功能码，实际效果取决于键盘型号与固件。逐键 RGB 仅适用于 RGB 型号；通用固件升级、全局宏录制和尚未验证的全局设备参数不在本版中。上文说明了范围受限的实验固件重刷工具。上述组合可使用按键校准，实际硬件行为仍待验证。
