# shadcn/ui

Local, themed shadcn/ui components based on the official New York registry (MIT), using Radix primitives. `components.json` configures future shadcn additions; shared colors and sizing come from `src/styles.css`.

Sources: https://github.com/shadcn-ui/ui/tree/main/apps/v4/registry/new-york-v4/ui

The application uses Button, Input, Textarea, Label, Checkbox, Select, Tabs, Dialog and AlertDialog. These are source components, so no runtime `shadcn` package is needed.
